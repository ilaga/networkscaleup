# compute numerically stable negative binomial rqr

compute numerically stable negative binomial rqr

## Usage

``` r
rqr_nbinom_logs(y, size, prob, eps = 1e-12)
```

## Arguments

- y:

  observed value

- size:

  size parameter

- prob:

  prob parameter

- eps:

  precision parameter

## Value

appropriate randomized quantile residual
