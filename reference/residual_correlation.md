# Construction Residual (row/column) correlation matrix

Construction Residual (row/column) correlation matrix

## Usage

``` r
residual_correlation(ard_residuals, ard, type = "column")
```

## Arguments

- ard_residuals:

  vector of residuals

- ard:

  ard matrix

- type:

  type of correlation to use (row or column)

## Value

a ggplot of the specified correlation matrix
